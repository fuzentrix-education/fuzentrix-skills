# Fuzentrix video guidelines

Every Fuzentrix Video follows these Video Sections, in order:

1. **Hook (≤ 20 s):** a relatable real-life question or scenario (e.g. "How does Instagram remember you?").
2. **Intro:** "Hello everyone, welcome to Fuzentrix. My name is …" + the topic in one line.
3. **Recap (if not the first video):** 2–3 points from the previous session.
4. **Agenda:** 3–5 points, shown as an agenda slide.
5. **Explanation:** one concept at a time, each as real-world example → concept → definition → technical example. Every concept in the Agenda must be covered.
6. **Summary:** a ✔ checklist that matches the Agenda exactly.
7. **Teaser / fun fact (optional):** must be fact-checked.
8. **Outro:** next-session preview + branded outro.

Visual rules: at least one visual change every 20–30 seconds, never more than one animation running at once, and all on-screen text in English.
